UNDER THE HOOD

Bubble Sort

Bubble Sort repeatedly compares neighboring values and swaps them when they are out of order. Large values gradually move toward the end.

How it works

  1. Compare two neighboring elements.
  2. Swap them if the left value is larger.
  3. Repeat passes until no swaps are needed.

    What is sorting?

    A sorting algorithm arranges values into a chosen order, here ascending from smallest to largest.

    02

    Why does it matter?

    Ordered data can be easier to scan, compare, summarize, and search. Sorting is a building block for many programs.

    03

    Three strategies

    Bubble swaps neighbors, Selection searches for the minimum, and Insertion places each new key into an already-sorted section.

    04

    Read the statistics

    Comparisons inspect values; swaps exchange two positions; shifts move values; writes record array assignments. Counts depend on both input and algorithm.

    Big-O describes how work tends to grow as the array gets larger. A single run is only one example—no algorithm is always fastest for every input.
